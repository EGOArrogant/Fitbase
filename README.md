# FitBase

Plataforma de entrenamiento y nutrición basada en evidencia.

Este repositorio publica las versiones de FitBase en **Releases**. Cada versión trae dos archivos:

- `fitapp-X.Y.Z.zip`: el paquete de la app.
- `version.json`: el manifiesto con la versión, la dirección del paquete y su firma SHA-256.

Las computadoras con FitBase configuradas con este repositorio (en *Actualizaciones → Repositorio de GitHub*) detectan e instalan las versiones nuevas solas. Tus datos (base de datos, fotos y configuración) nunca forman parte del paquete.
