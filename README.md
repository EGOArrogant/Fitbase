# FitBase

Plataforma de entrenamiento y nutrición basada en evidencia.

Este repositorio publica las versiones de FitBase:

- `version.json` (en la raíz): el manifiesto de la versión más reciente, con la dirección del paquete y su firma SHA-256.
- `versiones/fitapp-X.Y.Z.zip`: el paquete de cada versión.

También pueden publicarse en **Releases** desde la propia app (*Actualizaciones → GitHub → Publicar esta versión*).

Las computadoras con FitBase configuradas con este repositorio (en *Actualizaciones → Repositorio de GitHub*) detectan e instalan las versiones nuevas solas. Tus datos (base de datos, fotos y configuración) nunca forman parte del paquete.
